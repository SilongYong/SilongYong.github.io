This is a template blog post. Duplicate this file, rename it with a short slug such as 2026-05-18-my-post.html, then replace the title, date, and body text.

You can write normal paragraphs, add links, and reference local files. For example, a PDF in the paper folder can be linked as ../paper/ariadne.pdf.

When you add a new post, also add a matching entry to blog/index.html so it appears in the post list.
